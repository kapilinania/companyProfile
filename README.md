## ⚡ Overview

**ByteSerf** is a premium, high-performance IT agency and academy landing page designed with a Silicon Valley-grade aesthetic. Built by **Kapil Inania**, the platform showcases comprehensive IT services ranging from modern web development and SEO to custom AI automation, alongside an integrated tech academy offering internships and courses.

The UI/UX is heavily focused on a premium dark mode, glassmorphism, dynamic glowing micro-animations, and high user interactivity.

## ✨ Advanced Design Features

The platform boasts high-end front-end architecture, utilizing pure Vanilla technologies for lightning-fast performance without framework bloat.

- 🖱️ **Custom Interactive Glowing Cursor**: A physics-based, spring-eased mouse tracker with dynamic spotlight hover effects.
- 📜 **Global Scroll Progress Indicator**: A seamless neon progress bar traversing the top of the viewport.
- 🎨 **Glassmorphism & Neon UI**: Deep dark backgrounds (`#050505`) contrasted with cyberpunk-inspired linear gradients (`#00F0FF` to `#FF0055`).
- 📱 **Fully Responsive Architecture**: Perfect mobile, tablet, and desktop scaling using modern CSS Grid and Flexbox.
- 🧠 **Intersection Observer Animations**: Elements reveal themselves seamlessly as the user scrolls down the page.
- 🔎 **Advanced Technical SEO**: Fully configured JSON-LD schema markup, Open Graph meta tags, and Twitter Cards injected natively.

## ⚙️ Installation & Usage

Because ByteSerf is built on a vanilla stack, no complex build tools or `node_modules` are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kapilinania/companyProfile.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd companyProfile
   ```
3. **Launch the application:**
   - Simply open `index.html` in your favorite modern browser (Chrome, Edge, Firefox, Safari).
   - *Optional:* For the best development experience, run it using a local server like **Live Server** in VS Code.

## 🤝 Lead Generation Integration

The platform features a smart, non-intrusive **Call Back Request Modal**.
- It intelligently delays execution by `3.5s`.
- Uses `sessionStorage` and `localStorage` to prevent spamming users who have already closed the modal or submitted their data.
- Automatically routes lead data directly to the founder's WhatsApp using deep linking.
